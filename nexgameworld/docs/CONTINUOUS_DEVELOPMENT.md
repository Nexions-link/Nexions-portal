## Путь релиза

1. Проверить свежий `main`, diff, синтаксис и тесты. Согласовать `server/index.js` (`BUILD`), `planet-test/version.json` и `planet-test/index.html` (`data-build`); выполнить release-consistency test. Обновить cache-busting импортов изменённых модулей.
2. После проверок внести коммит через штатный процесс. Push в `main` запускает `NexGameWorld Spherical and Server CI`, `NexGameWorld server checks`, `NGW VPS deploy` и уведомление зеркала. Дождаться успешного фактического VPS-деплоя с тем же BUILD.
3. Подтвердить успешный `Sync NexGameWorld to nexions.ru` в `Nexions-link/Nexions-portal`. Этот workflow повторяет клиентские проверки, выполняет checksum rsync, записывает `nexgameworld/upstream-commit.txt`, коммитит и запрашивает Pages rebuild. Не заменять его ручным копированием.
4. Сверить файлы зеркала с source и `upstream-commit.txt`. Проверить последний успешный системный `pages build and deployment` на коммите портала, содержащем обновление.
5. Дождаться свежего зелёного `Verify live NexGameWorld on nexions.ru` после Pages. Это внешний аудит `ops/audit-production.mjs`, проверяющий публичный клиент, SHA, модули, API и отсутствие ошибок сохранения. При необходимости штатно запустить `verify-live-game.yml` через workflow_dispatch. Проверить публичные изменённые JS/ресурсы и фактический WebGL-результат.
6. Только после всех шлюзов писать «опубликовано, можно тестировать». Иначе сообщать точный достигнутый этап и блокировку.

Команды наблюдения: `gh run list --repo Nexions-link/Nexgame --commit <SHA>` и `gh run list --repo Nexions-link/Nexions-portal`. Системный Pages при необходимости искать через `gh api repos/Nexions-link/Nexions-portal/actions/runs?per_page=100`: фильтр `gh run list --workflow 'pages build and deployment'` может его не находить.
