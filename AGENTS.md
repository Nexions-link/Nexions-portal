# Nexions.ru — обязательный релизный шлюз NexGameWorld

Это требование действует **в любом чате проекта NexGameWorld** и при любом обновлении игры, страницы входа, маунтов, моделей, Atlas или сервера.

- Основной код: `Nexions-link/Nexgame/main`. Сайт: `https://nexions.ru/nexgameworld/`. Репозиторий `Nexions-link/Nexions-portal` является зеркалом, но коммит в зеркале **не доказывает**, что сайт уже изменился.
- Прежде чем сообщить пользователю «обновлено», «готово», «опубликовано» или «можно тестировать», проверь успешные GitHub Actions исходного клиента/сервера, `Sync NexGameWorld to nexions.ru`, последний `pages build and deployment` и итог `Verify live NexGameWorld on nexions.ru` **после обновления**.
- Сверь `Nexgame/planet-test/version.json`, `index.html` и версию сервера `Nexgame/server/index.js` (BUILD); все должны соответствовать единому релизу. Статические файлы, `upstream-commit.txt` и нужные модули должны совпадать с исходным `main`.
- Обязательно проверь **публичную выдачу** `https://nexions.ru/nexgameworld/planet-test/version.json`, `index.html`, нужных JS/CSS, работоспособность игрового загрузчика и готовность Render. Используй `Nexgame/ops/audit-production.mjs` и GitHub Actions `Verify live NexGameWorld on nexions.ru`.
- Если live-проверка красная, не запускалась после релиза или недоступна из текущей среды, нельзя утверждать, что сайт готов: сообщи честно «код отправлен, публикация сайта не подтверждена», укажи проблемный этап и GitHub Actions ссылку.
- **Не обходи падающий CI ручным копированием файлов в зеркало**, не называй совпадение SHA или версии достаточным основанием для готовности.
- В начале работы над NexGameWorld из нового чата прочти `Nexions-link/Nexgame/AGENTS.md`, этот файл и статус последних рабочих процессов.

26.10.2026 наблюдалась ошибка: исходная 0.6.45.21 и зеркало GitHub совпадали, но публичный сайт показывал 0.6.45.20, а CI/производственный аудит были красными. Данный шлюз обязателен во всех дальнейших работах.
